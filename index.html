STRVCT

A naked-objects framework for JavaScript

About

You write the domain model. The framework handles the rest.

STRVCT implements the Naked Objects pattern: annotated model classes (inheriting from SvStorableNode) serve as the single source of truth for your application. From slot metadata annotations, the framework derives responsive, orientation-flexible master-detail views (Miller columns, side-by-side tabs, and inline document section flows) that compose recursively across the domain object graph, manages local-first IndexedDB object pools, handles versioned cloud synchronization, and provides a constant-size tool surface for AI agents.

Because domain models carry explicit metadata and remain completely independent of the view layer, the same application code runs natively in the browser, on the command line, or headlessly in Node.js for ultra-fast unit testing.

Architecture Overview

Model-First Syntax

Declare domain models as JavaScript classes. Properties are declared as slots enriched with metadata annotations that each framework layer reads independently:

(class Task extends SvStorableNode {

    initPrototypeSlots () {
        {
            const slot = this.newSlot("title", "New Task");
            slot.setSlotType("String");
            slot.setShouldStoreSlot(true);   // Persisted to IndexedDB
            slot.setSyncsToView(true);       // Live UI updates
            slot.setCanEditInspection(true); // Editable field tile
        }
        {
            const slot = this.newSlot("isCompleted", false);
            slot.setSlotType("Boolean");
            slot.setShouldStoreSlot(true);
            slot.setSyncsToView(true);
            slot.setCanEditInspection(true);
        }
    }

    initPrototype () {
        this.setTitle("Task");
        this.setShouldStore(true);
    }

}.initThisClass());

Key Framework Capabilities

  • Recursive Master-Detail Engine — Derives orientation-flexible Miller columns, side-by-side tabs, and inline document section flows that compose recursively across the object graph and collapse automatically on narrow viewports.
  • Multi-Reader Slot Annotations — Slot metadata drives form generation, type validation, local persistence, notification triggers, Property Inspector fields, and LLM JSON schemas without glue code.
  • Natively AI-Operable — Exposes a constant-size tool surface (schema-fetch and apply-patch) across all domain classes, allowing LLMs to inspect schemas and patch live object graphs with automatic validation.
  • Local-First & Cloud Sync — Automatic dirty tracking commits modifications to IndexedDB at the end of each event loop. Syncs versioned atomic deltas to cloud stores.
  • Headless Node.js Execution — Domain models hold zero DOM dependencies, running headlessly in Node.js for ultra-fast unit testing and batch processing.
  • Derived Accessibility & Localization — ARIA roles, focus management, keyboard navigation, and AI string translations are handled centrally at the tile primitive boundary.
  • Content-Addressable Memory (CAM) — Scans source imports to build SHA-256 content-hashed bundles for optimal caching and zero-churn redeployments.
